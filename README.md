# ROYCE

A frontend-only cinematic site for a fictional luxury marque. Next.js 16, React 19, TypeScript, Tailwind CSS 4, GSAP ScrollTrigger, Lenis, Motion (UI only).

```bash
npm install
npm run dev               # http://localhost:3000
npm run build && npm start
npm run validate:assets   # size and sharpness check for every photograph
```

## The film, chapter by chapter

| # | Chapter | File | Identity and motion |
| --- | --- | --- | --- |
| 01 | Arrival | `components/film/FilmSequence.tsx` | Scroll is the video playhead: pinned, scrubbed frame by frame, reverses on scroll up |
| | The collection | `components/ModelsIndex.tsx` | Showroom index of all seven models; slides over the end of Film 01 |
| | Phantom | `components/PhantomChapter.tsx` | Architectural and symmetric: centre-split reveals, slow push-ins, drawn hairlines |
| 02 | Ghost | `components/cinema/scripts.ts` | One continuous camera: dark stage, dusk, into the coach door, through to the cabin, back out |
| | Cullinan | `components/CullinanChapter.tsx` | The daylight chapter: pinned horizontal panorama with a depth layer |
| 03 | Spectre | `components/cinema/scripts.ts` | Night and light: lamps coming on, light-band sweeps, lateral tracking |
| | Black Badge | `components/BlackBadge.tsx` | Hard-cut montage with the manifesto, one word per cut |
| 04 | Craftsmanship | `components/cinema/scripts.ts` | Macro push-ins, one material at a time |
| | Heritage | `components/Heritage.tsx` | Timeline with archival crossfades, monochrome to colour |
| | Gallery | `components/Gallery.tsx` | Detail gallery with a full-screen viewer |
| 05 | Finale | `components/cinema/scripts.ts` | The lights come up as the camera pulls back; the footer rises over it |

Chapters 02 to 05 run on one engine, `components/cinema/CinematicChapter.tsx`. A chapter is data: a shot list (photograph, camera move, transition), editorial beats keyed to the same timeline, a scroll distance per device class, and optional video and image-sequence sources. Transitions: cut, dissolve, wipes, iris, split, from-dark, light sweep.

## Media

Everything is declared once in `src/lib/media.ts`:

- **Photographs** live in `public/assets/rolls-royce/<group>/<name>.webp`, every one at the largest size its original allows (up to 3840px wide; landscapes are 3840 wide, portraits up to 3840 wide and 5760 tall). Replace any file with an approved original under the same name (export WebP, quality 84, at least 3840 on the long edge), then run `npm run validate:assets`. Missing or failed files fall back to a still of the arrival film, never an empty box, and while a photograph loads its own tiny blurred preview (stored in `src/lib/asset-manifest.json`) holds the frame; after replacing a file, run `node scripts/blur-placeholders.mjs`. The optimizer serves WebP only: measured on the hero photographs, AVIF at the same quality setting lost about a sixth of the fine detail.
- **Registration plates** in `heritage/wraith` and `heritage/silver-cloud` were blanked in the files themselves (originals in the workspace's `audit/originals/`). `npm run ingest:assets` keeps retouched files unless run with `--force`.
- **Films**: drop an all-intra MP4 at any of these paths and that chapter switches from its shot list to scrubbing the video, with no code changes:
  `public/videos/ghost.mp4`, `craftsmanship.mp4`, `spectre.mp4`, `finale.mp4`.
- **Image sequences**: frames named `frame-0001.webp` … `frame-0060.webp` in `public/sequences/ghost-door/` play inside the Ghost chapter as the door opens. Frames load coarse to fine and only a small window is decoded at a time, so memory stays bounded.

Encode films for scrubbing with a keyframe on every frame, or seeking backwards stutters:

```bash
ffmpeg -i source.mov -an -vf "scale=1920:-2,format=yuv420p" -c:v libx264 -preset slow -crf 22 -g 1 -keyint_min 1 -sc_threshold 0 -movflags +faststart public/videos/ghost.mp4
ffmpeg -i source.mov -an -vf "fps=24,scale=1920:-2" -c:v libwebp -quality 80 public/sequences/ghost-door/frame-%04d.webp
```

The arrival film is the supplied 1920x1080, 24 fps source re-encoded all-intra at CRF 15 (SSIM 0.990 against the source), reframed to 1776x1000 to leave the generator watermark outside the frame, with no upscaling; the phone cut is an 800x1000 crop of the same source, and the posters are the source's first and last frames.

## Instruments

Each film chapter carries a thin progress rule (right edge on desktop, under the navigation on phones and tablets) driven by its scroll timeline. Chapter labels, frame counters, timecodes and plate numerals were removed from the public page by request; the rules stayed so the motion is unchanged.

## Development photography

The current photographs are stand-ins from Unsplash (see `IMAGE-CREDITS.md`, regenerated by `npm run ingest:assets`). They show Rolls-Royce vehicles and trademarks. For launch, replace them with owned or officially licensed photography: for example originals downloaded manually from the Rolls-Royce Motor Cars PressClub model galleries (Ghost, Spectre, Cullinan, Phantom Extended, Black Badge), subject to its terms.
